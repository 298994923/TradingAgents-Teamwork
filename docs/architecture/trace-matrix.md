## Reading the evidence

- **Mapped:** the cited source and test surface exists; this is not a fresh pass
  or a complete guarantee beyond the named scope.
- **Partial:** only a subset or related primitive is evidenced.
- **Historical / deferred / pending:** external coursework material or intended
  paths do not establish a current team-main implementation.
- **Fit criterion review:** the E entry's positive success metric has a zero
  threshold. Preserve the submitted requirement and obtain a meaningful owner-
  confirmed criterion before calling it accepted.
- **External proof:** repository files cannot verify GitHub branch settings.

A runtime observation may be an API result, exception, state field, stored
artifact, CI result or a manual audit. These are identified by kind below;
there is no implied background monitor, alerting service, collection dashboard
or complete production instrumentation. Missing observations require owner
confirmation, not invented evidence. Test references marked absent are deliberate
gap records, not broken links represented as available tests.
