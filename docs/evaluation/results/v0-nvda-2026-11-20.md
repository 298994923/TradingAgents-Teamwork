## Caveats — read before using these numbers

1. **`prompt_hashes: {}`** in all three (B's patch not merged). The comparison tool
   rejects them; no prompt-version claim can be made.
2. **`stop_reason: null`** (C's field not wired into the graph).
3. **`evidence_snapshot: null`** (A's module not in the repo).
4. **Run-to-run variance**: first run took 446 s vs 165–182 s for the others with
   nearly identical token counts. Cause not diagnosed; do not treat the mean as a
   stable V0 cost without more samples.
5. These manifests were produced after the E-side fixes (`results_dir` removed from
   `config_snapshot`, null-token handling). Checked: `results_dir` is absent from all
   three `config_snapshot`s.
