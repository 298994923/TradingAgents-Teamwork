# Collaboration protocol and context management

FuKaichao (60468706), Package B. Report chapter for team integration.

The second researcher originally received the first researcher's argument in the shared history. Package B gives each first-round researcher an independent input and restricts later responses to assigned earlier claims. Each accepted claim has an attributable speaker, evidence references and a round index. One bounded format repair is available. When validation fails, the system carries the failure and recoverable disagreement information forward. The manager returns the adopted and rejected IDs, their reasons and open bull/bear pairs.

The context builder orders identity, hard constraints, evidence, current task, history and resume state. At the configured threshold it removes eligible material according to priority, records the reason and verifies the ordered identities and exact text fingerprints of protected blocks. If the mandatory context cannot fit, the call stops. The estimator measures serialized text locally; provider manifests establish actual input usage.

In the matched S7 replay, both legacy opening prompts exposed the opposing claim and neither collaborative opening did. Both targeted replies retained valid links. S9 tested four scenarios three times each with CityU DeepSeek. All six targeted replies linked correctly and all thirty measured evidence references resolved against the fixture. Three matched compactions reduced observed input usage from 460 to 374 tokens and preserved the hard constraint each time. The manager retained the open pair in all three trials. No live repair occurred. These results cover this fixed set; the experiment did not evaluate investment returns, persuasion quality or full-graph termination.
